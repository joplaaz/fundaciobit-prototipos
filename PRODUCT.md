# Prototipos Fundació BIT

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

HTML, CSS y JavaScript estáticos. El usuario ha confirmado GitHub Pages como destino y ha solicitado crear y publicar el repositorio. Sin instalación, compilación ni dependencias de servicios externos en la aplicación.

## Users

Personas que evalúan las propuestas de la memoria; visitantes, empresas residentes y emprendedores que consultan servicios, agenda, espacios y movilidad.

## Product Purpose

Convertir las propuestas visuales de la memoria en seis prototipos navegables conectados, que se puedan abrir localmente y publicar en GitHub Pages.

## Capabilities and Constraints

Portada, ficha de servicio, agenda, directorio con mapa, visor cartográfico y planificador con sostenibilidad. Los formularios y cálculos son simulaciones locales. Empresas, aforos, disponibilidad, rutas y métricas son datos sintéticos identificados como demostración. El mapa es esquemático, no un servicio de navegación geográfica. No hay backend, tramitación real, envíos, datos GTFS, seguimiento de ubicación ni almacenamiento de datos personales.

## Brand Commitments

La memoria suministrada define el nombre Fundació BIT, el azul institucional, el turquesa y una interfaz limpia. Se hereda ese lenguaje visual de las maquetas existentes. No se atribuye carácter oficial a esta implementación.

## Evidence on Hand

Memoria subjetiva-12.docx, páginas del pie 40–42, 60, 73–75, 80, 85–87 y 91–92. Las maquetas del documento son la referencia de las pantallas; no se incluyen el documento original ni sus datos corporativos en la web.

## Accessibility & Inclusion

Diseño adaptable a móvil, teclado, foco visible, etiquetas, avisos de estado y contraste alto. Selector de idioma para la interfaz en castellano, catalán e inglés. La demo no constituye una certificación de cumplimiento WCAG.
